TextCrypt

Modo seguro de cifrado de texto

Qué hace esta versión Cifra texto con AES-256-GCM y deriva la clave desde una contraseña con PBKDF2-HMAC-SHA-256. El paquete exportado incluye la sal, el vector de inicialización y los datos cifrados, pero nunca la contraseña. Usa una frase de contraseña larga y única.

Límite de esta versión: 2 MiB de texto UTF-8.

Para cifrar se requieren al menos 12 caracteres. Para descifrar, utiliza exactamente la misma contraseña.

Esta página procesa los datos en el navegador y no contiene código para enviarlos a un servidor. Aun así, no introduzcas secretos importantes en una página cuyo código o dispositivo no controles. Para usar Web Crypto API, ejecuta esta página en HTTPS o en un servidor local como http://localhost.
